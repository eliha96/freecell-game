# פריסל קלאסי - FreeCell Classic

משחק פריסל (FreeCell) קלאסי, נקי, מודרני וללא פרסומות, מותאם במיוחד למובייל ולמחשב.

## תכונות עיקריות

- **אותנטיות מלאה (Windows 95/XP):**
  - אלגוריתם חלוקת קלפים מקורי של Microsoft CRT LCG עם כל 32,000 מספרי המשחק המקוריים (כולל Deal #1, Deal #617, ומשחק #11982 הבלתי-פתיר המפורסם).
  - עיצוב פיקסל-ארט מקורי של סוזן קאר (`cards.dll`) כברירת מחדל נוסטלגית.
  - אפשרות לעיצוב קלאסי תקני (וקטורי Bicycle נקי).

- **חוויית משחק מותאמת אישית למובייל ולמגע:**
  - פריסה נוחה של 8 עמודות מותאמת למסכי סמארטפון לאורך ולרוחב.
  - תמיכה מלאה בגרירה ושחרור (Drag & Drop) של קלף בודד או רצף קלפים לפי חישוב Supermove ($M = (1 + \text{emptyCells}) \times 2^{\text{emptyColumns}}$).
  - הקשה חכמה (Tap-to-Move): העברה מהירה של קלף ליעד הטוב ביותר בלחיצה בודדת.
  - העברה אוטומטית בטוחה של קלפים לבסיס (Safe Auto-Play).
  - סיום אוטומטי מהיר ואלגנטי ברגע שהלוח פתור.

- **נוחות ושליטה:**
  - ביטול ושחזור מהלכים ללא הגבלה (Undo / Redo).
  - שעון וסופר מהלכים.
  - צלילי משחק עדינים ורטט מגע (Haptics) ללא תלות ברשת (100% Offline דרך Web Audio API).
  - תמיכה מלאה בהתקנה כאפליקציית PWA לסמארטפון ללא צורך בחנות אפליקציות.
  - ללא פרסומות, ללא מעקב וללא הסחות דעת.
